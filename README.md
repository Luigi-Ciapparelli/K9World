# PortaleCinofilo

Portale gratuito per conoscere il cane, orientarsi fra professionisti e mantenere
continuità nel lavoro sul binomio. `K9World` è il nome del repository.

Sito: [www.portalecinofilo.com](https://www.portalecinofilo.com).

**Per riprendere il lavoro, partire da [START_HERE.md](START_HERE.md).**
Lo [stato corrente](docs/CURRENT_STATE.md) distingue codice pubblicato su GitHub,
riscontri online, limiti e lavoro futuro. Le [direttive](docs/PRODUCT_DIRECTION.md)
definiscono il prodotto; le [priorità](docs/EXECUTION_PRIORITIES_2026_10.md) ordinano il lavoro.

Stack: React, TypeScript, Vite, Supabase e Vercel. Nessuna credenziale nel repository.
